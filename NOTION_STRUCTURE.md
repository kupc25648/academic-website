# Suggested Notion Structure

The website no longer assumes everything lives in Notion.

## Research Arcs

Keep the long-form research pages in Notion if useful.

Website fields:

- Arc Number
- Title
- Subtitle
- Website Summary
- Key Questions
- Recommended Skills
- Tags
- Featured Figure
- Public URL

## Courses

Recommended relational model:

### Course database

- Course Code
- Course Name
- Description
- Topics

### Offering database

- Course relation
- Academic Year
- Semester
- Offering Title
- URL
- Source
- Syllabus
- Public

This is better than creating an unrelated course record for every year.

## People

People can remain website-only.

Optional fields:

- Name
- Role
- Start Year
- End Year
- Research Topic
- Website
- LinkedIn
- ORCID
- Google Scholar
- Portfolio

## News

Do not force News into Notion.

Fields:

- Date
- Type
- Title
- Summary
- Source
- URL

The URL can be any public destination.
